# 一次性脚本（跑过就完事的那些）

这里放**用完即弃**的脚本：各册的配图脚本 `<模块>_figs.py`、日期前缀的回流／建页／
组装脚本、以及一次性的增章构建器。它们留档是为了「当时到底怎么改的」有据可查，
**不是给人再跑一遍的**（不少还停在旧布局口径上，直接跑会出错）。

**为什么单独一层**（2026-08-03 工程审视时分）：此前 105 个文件平铺在 `_maintenance/` 一层，
一次性件与 CI 依赖的常设门禁混在一起，回答不了「哪些脚本是承重的」——
实测有 14 个 `.py` 在全库任何文档里零引用。

分层之后上一层有了一条可判定的性质：**`_maintenance/` 顶层的每个 `.py`／`.sh` 都是常设件，
都必须在技能源目录里有对应**（`check_scripts_sync.py` 现在直接照这条判，
不再靠文件名正则猜哪个是一次性的）。要加一次性脚本，放这一层，不会被那道门禁盯上。

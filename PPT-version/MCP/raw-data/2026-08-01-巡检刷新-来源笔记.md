## 二、信源（全部一等源，逐条当场核实 2026-08-01）

1. **Python SDK v2.0.0 — 正式版、2026-07-28**
   `https://api.github.com/repos/modelcontextprotocol/python-sdk/releases`
   tag `v2.0.0`，published 2026-07-28，`prerelease: false`。发布说明原文要点：支持
   2026-07-28 revision（无握手的无状态请求、`server/discover`、`subscriptions/listen`、
   多轮请求），且同一个 `MCPServer` 仍能服务 2025 系客户端；装饰器 API 不变，底层
   `Server` 换成共享 dispatcher，`Client` 一个对象取代 v1 的 transport + ClientSession +
   initialize 三层。
   → 这条同时坐实了「FastMCP 更名 MCPServer」在正式版里落定，不再是 beta 阶段的说法。

2. **v1 转维护线 — v1.29.0，2026-07-28**
   同一 releases 接口：tag `v1.29.0`，published 2026-07-28，`prerelease: false`；
   发布说明含「Move the v1.x docs to /v1/ and mark v1.x as the maintenance line」。
   v2.0.0 的说明里进一步写明 v1.x 只收安全修复，并建议未准备升级的钉 `mcp>=1.28,<2`。
   **措辞注意**：巡检报告里写的是「终版 v1.29.0」，但官方只说 v1 是维护线、只收安全修复
   ——安全修复本身还会出新 v1 版本，所以成品与账本一律写「当前 v1.29.0」「转维护线」，
   不写「终版」。

3. **TypeScript SDK 2.0.0 — 拆包、2026-07-27**
   `https://api.github.com/repos/modelcontextprotocol/typescript-sdk/releases`
   同日（2026-07-27）并排发出 `@modelcontextprotocol/core@2.0.0`、`client`、`server`、
   `server-legacy`、`node`、`express`、`hono`、`fastify`、`codemod` 一组包，均 `prerelease: false`；
   另有 `1.30.0`。发布说明写明 schema 源模块（spec schemas、OAuth schemas、协议常量）
   收进 `@modelcontextprotocol/core` 作为运行时依赖，不再各包各带一份私有副本。
   → 「TS v2 拆包」这个说法成立，本次把拆成了哪些包写实。

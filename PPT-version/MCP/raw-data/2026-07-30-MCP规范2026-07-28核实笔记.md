## 九项主变更（相对 2025-11-25）

1. 删协议级会话与 `Mcp-Session-Id`；列表端点不再随连接变化；跨调用状态改用**服务端铸造的句柄**当普通工具参数传（SEP-2567）
2. 删 `initialize`/`notifications/initialized` 握手；每请求 `_meta` 自带 `protocolVersion` 与 `clientCapabilities`；不匹配返回 `UnsupportedProtocolVersionError`（SEP-2575）
3. 新增 `server/discover`，服务端 **MUST** 实现（SEP-2575）
4. 删 HTTP GET 端点与 `resources/subscribe`/`unsubscribe`，改单条长连 `subscriptions/listen`（SEP-2575）
5. 删 `ping`、`logging/setLevel`、`notifications/roots/list_changed`；日志级别改每请求 `_meta` 带（SEP-2575）
6. Tasks 出核心入官方扩展 `io.modelcontextprotocol/tasks`；`tasks/result` → `tasks/get` 轮询 + 新增 `tasks/update`，删 `tasks/list`（SEP-2663）
7. MRTR 取代服务端发起请求：返回 `InputRequiredResult`，客户端带 `inputResponses` 重试（SEP-2322）
8. 所有结果必带 `resultType`；旧版省略按 `complete` 处理（SEP-2322）
9. 删 SSE 流可恢复与重投（`Last-Event-ID`）；断流须以新请求 ID 重发（SEP-2575）

## 次要变更里对售前有用的

- `Mcp-Method` / `Mcp-Name` 成为 POST 必带头，网关/限流器/WAF 不解 JSON 体即可路由（SEP-2243）
- 五个列表类结果必带 `ttlMs` / `cacheScope`（SEP-2549）；`tools/list` 建议确定性顺序以提高提示词缓存命中
- OpenTelemetry trace context 进 `_meta`（`traceparent`/`tracestate`/`baggage`，SEP-414）
- 授权三条：`iss` 校验（RFC 9207，SEP-2468）、注册声明 `application_type`（SEP-837）、凭据按签发方绑定（SEP-2352）
- 错误码：资源未找到 `-32002` → `-32602`；新增分配政策（`-32020`–`-32099` 规范保留）

## 四项弃用与窗口

Roots / Sampling / Logging（SEP-2577）、HTTP+SSE 传输（SEP-2596）、`includeContext` 的
`thisServer`/`allServers`（SEP-2596）、OAuth 动态客户端注册转 CIMD（PR #2858）。

**口径要说准**：十二个月是「弃用到最早可移除」的窗口，**不是**「新版本只管十二个月」。
说岔了会变成给客户的错误承诺。

SDK：四个 Tier 1（TypeScript / Python / Go / C#）已出支持版本，Rust 为 beta。

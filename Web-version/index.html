网页版 · 全库视图

搜索直达任何模块、章节、已核实的事实、现场问答和关键技术词；跨模块关系与保鲜排期在这一页看全。每章末尾还有一条串联行，从这一章牵到相关主题的落点。按问题找答案去全库问答库，拿不准一个词在库里指哪件事去全库术语表；知识地图与每日取用在首页。

    搜索需要 JavaScript；未启用时可从顶栏回首页按层查找，或直接翻全库问答库（不需要 JavaScript 也能整页读完）。

    按问题找客户问的话，多半已经有人问过

    21 册各印各的「现场高频追问」，加上实战包的电梯版交锋题，全汇在全库问答库——搜一句话就能找到它在哪册、答案是什么。那一页只登记题目与去处，答案留在原处，所以不会出现两处各说一套。

    另一半是词：同一个词在两册指两件事（漂移、训练、评估、平台……），或者两个词常被当成一件事——这类认错了，两边的人会一路谈到验收才发现说的不是同一件事。全库术语表专收这种，一句话加一个去处。

    知识地图 · 链接图

    全库 21 个模块按七层排开（和 PPT 总览同一套层级），模块之间的连线是「讲这一块时该带上的另一块」——关系登记在各模块清单的「串联出边」里，这里把它们连成一张图。21 册讲义各印各的、纸面上没法互相指，这是网页版才做得到的事。

    按 7 层排布的全库 21 个模块。两种学法——单点学习：直接点模块进那一册；关联学习：点一个模块，它滑到中间、散开它的关键技术词；点一个词就跳到讲它的那一章去读，同时散开相关的词，顺着技术名词一步步深挖。

    关联＝点模块散关键词、顺着技术名词深挖；单点＝直接进册

    「单点学习」点模块直接进册；「关联学习」下点模块散开它的关键技术词，点一个词跳到讲它的那一章、并散开相关词，最多联想 3 步；点中心可读该册，按返回全景 / Esc 回总图。需要逐条读关系，展开下面的文字表。
